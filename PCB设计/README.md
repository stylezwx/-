# 智能宠物烘干箱控制板

本目录是依据当前 STM32 与 ESP32 固件整理的立创 EDA 专业版建板资料。目标板为
100 mm x 80 mm、双层、1.6 mm FR-4、1 oz 铜厚的低压控制板。

## 安全边界

本板只处理 12 V DC 和 3.3 V 逻辑信号。220 V AC 加热器不得直接接入本 PCB，必须使用
带认证外壳的外置零交越固态继电器或接触器。加热器火线还必须串联独立机械温控器、一次性
温度保险丝和急停开关。控制软件、DHT11 和本板均不能作为唯一过温保护。

## 立创 EDA 专业版建板顺序

1. 新建工程 `PetDryerController`，原理图单位使用公制。
2. 按 `原理图网络表.csv` 放置器件和连接网络，器件参数及封装见 `BOM.csv`。
3. ERC 后更新至 PCB，板框按 `PCB布局与规则.md` 建立为 100 mm x 80 mm。
4. 完成布局、布线、铺 GND 铜，运行 DRC。
5. 根据 `生产检查清单.md` 复核后再导出 Gerber、钻孔、BOM 和坐标文件。

## 与现有固件兼容的引脚

| 功能 | STM32 引脚 | 说明 |
|---|---:|---|
| K1/K2/K3/K4 | PA0/PA1/PA2/PA3 | 低电平按下 |
| FAN_PWM | PA6/TIM3_CH1 | 25 kHz，经开漏缓冲输出 |
| USART1_TX/RX | PA9/PA10 | 115200 bit/s |
| DHT11_1/2 | PA11/PA12 | 单总线 |
| OLED_SCL/SDA | PB8/PB9 | 软件 I2C |
| HEATER_EN | PB11 | 固件低电平有效 |
| PET_PRESENT | PB12 | 低电平表示在位 |
| BUZZER | PB13 | 有源蜂鸣器驱动 |
| STATUS_LED | PC13 | 低电平点亮 |

## 必须在投板前确定

- J7 是 PC817 光耦的浮地晶体管输出，应接外置 SSR/接触器的低压控制回路；其控制电流建议不超过 20 mA。
- 四线风扇接口引脚顺序必须根据所购风扇数据表复核，不能只按线色判断。
- 当前固件未采集风扇 TACH。硬件已预留 PB14 输入，但要使用堵转检测需增加固件逻辑。
- ESP32-S3 仍按独立开发板和 USB 串口工作，不与 STM32 UART 直连，以保持当前上位机双串口架构。
