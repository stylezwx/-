# 生产检查清单

- [ ] 原理图 ERC 无未解释错误，所有电源引脚均连接并去耦。
- [ ] STM32 的 BOOT0 使用 10 kΩ 下拉，BOOT1/PB2 状态明确。
- [ ] NRST 引出且 SWDIO、SWCLK、GND、3V3 排列无误。
- [ ] PB11 上电默认状态不会启动加热，断电与 MCU 复位均使外置 SSR 关闭。
- [ ] 外置 SSR 的输入电压、电流和有效极性与 J7 匹配。
- [ ] 外置 SSR/接触器额定值按加热器功率至少留 50% 余量，并配置散热器。
- [ ] 220 V 回路使用独立保险丝、急停、机械温控器和一次性温度保险丝。
- [ ] 风扇实物接口顺序与 J2 丝印一致，PWM 为开漏输出，TACH 不承受 5 V 直灌。
- [ ] 12 V 风扇通路在最窄处仍满足 2 A，连接器额定电流不小于 3 A。
- [ ] 安装孔、连接器方向、箱体开孔与线束长度完成 1:1 打印校验。
- [ ] PCB DRC 无错误，铜皮到板边不小于 0.3 mm。
- [ ] 首次上电使用限流电源，先不接风扇、SSR 和加热器。
- [ ] 依次验证 3.3 V、时钟、SWD、串口、传感器、OLED、PWM 和报警输出。
- [ ] 使用示波器确认风扇 PWM 约为 25 kHz，0%/100% 状态符合风扇规范。
- [ ] 在接入加热器前，以指示灯或小信号负载验证全部正常/故障状态。
